# 查单词 · 小米手环 8 Pro

手环上用的离线查词小工具。26 个小写字母自带键盘，打一个词就出音标和释义，不联网、不要账号。

- 安装包：`dist/com.dsh.banddict.debug.1.2.1.rpk`（约 165KB）
- 词库：6530 词 = 高考 3500 词表 3613 条 + 六级新增 2917 条（都只收**纯小写字母**的词）
- 界面：336 × 480 竖屏，深色
- 在线预览：`preview/preview.html`（浏览器里点键盘就能试）

## 安装

和背单词应用一样，用 AstroBox 蓝牙侧载（小米手环 8 Pro 跑的是 Xiaomi Vela，装不了普通 APK）：

1. 手机装 [AstroBox](https://astrobox.online)，登录小米账号（与手环同一个）
2. 后台强行停止「小米运动健康」，避免和设备抢连接
3. 手环进「设置 → 连接新手机」，用 AstroBox 配对
4. 把 `com.dsh.banddict.debug.1.2.1.rpk` 拖进 AstroBox（或设备页 → Quick app → +）
5. 手环应用列表里出现绿色放大镜图标

图标是 96×96，只占一格。

## 使用

| 位置 | 操作 |
| --- | --- |
| 键盘 | 字母顺序 a→z，一排 5 个键（6 行），键位 58×56，键盘区可上下滑；打满 24 个字母停止 |
| 删除 / 清空 | 固定在键盘下方，不随滚动；删除退一个字母并立即重查，清空回到起始界面 |
| 结果区 | 命中时显示单词、音标、词性释义；释义长可上下滑 |
| 未命中 | 显示「没收录这个词」和「最接近 xxx」，点按钮直接跳到那个词 |

搜索是边打边查的：每敲一个字母就重新查一次，命中立刻显示，不需要确认键。

## 词库

两处来源，合并后按字母升序存：

| 来源 | 条数 |
| --- | --- |
| 高考 3500 词表（与背单词应用同一份，去重后） | 3613 |
| 六级词书（kajweb/dict 的 CET6_1/2/3 与 CET6luan_1 去重合并） | +2917 |
| **合计（纯小写）** | **6530** |
| 丢掉：含大写字母（Africa、AIDS、Christmas…） | 154 |
| 丢掉：带空格 / 连字符 / 撇号 / 重音符（ice cream、best-seller、o'clock、café…） | 103 |

因为这些字符键盘上打不出来，收进来也查不到，所以生成词库时就过滤掉了。

生成脚本 `tools/build-words.js` 可直接重跑，它会读 `../bandwords/src/common/wordlist.js`（3500 表）和 `tools/cet6.json`（六级词书抽取结果），写 `src/common/worddata.js`。

## 音标为什么是 `'ap(e)l` 这种写法

手环的系统字体只覆盖拉丁字母，国际音标里的 `ɪ ə ʃ θ ŋ ː` 这些字形是空的，直接显示会缺字甚至串行。
所以音标统一转成 ASCII 近似记法：`ʃ→sh`、`θ→th`、`ŋ→ng`、`ɪ→i`、`ə→e`、`ː→:`、重音 `ˈ→'`。
`apple` 显示成 `/ 'ap(e)l /`，读起来和 IPA 对得上。六级词书带的是 IPA，同一套 `tools/ipa-ascii.js` 转换。

## 性能是怎么保证的

| 做法 | 效果 |
| --- | --- |
| 精确匹配走**二分查找** | 6530 词最多 13 次比较，单次查询实测 < 2µs |
| 词条只在**第一次查询时** `split("\n")` 一次 | 之后复用，不重复解析 210KB 字符串 |
| 额外抽出「单词」数组参与比较 | 二分时不再每步切字符串找 `\|` |
| 词表按字母**升序**存在生成阶段 | 运行时不做排序 |
| 大数组放在**模块作用域**，不进组件 `private` | 不参与视图层数据代理与 diff |
| 键盘是**静态节点** | 敲字只更新输入框和结果区，26 个键不重渲染 |
| 词库只进这一个页面 | `app.js` 只有 4KB，其它包体不含词条 |
| 词库压成「一行一词、`\|` 分隔」的字符串 | 避免 Babel 把嵌套数组逐项缩进展开（会膨胀 4 倍） |

## 已知限制

- 词库是 3500 表 + 六级词书的并集，不是全词典：`photosynthesis`、`quarantine`、`sushi` 这类词查不到
- 没做发音（手环没有词典音源），只有文字
- 不联网，词库随包发布，改词库要重新打包
- 未命中时只给一个最接近的词，不做模糊/前缀联想列表
- 手环系统固定竖屏，做不了横屏；一排 5 个键时 6 行放不进一屏，所以键盘区是可滑动的，最下面两行要滑一下才看得到
